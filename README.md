ftl
===

Forward to Libraries service (selected code and data)

Code lives in the code subdirectory, data in the data subdirectory,
documentation in the docs subdirectory.

Not all information required to run this service is currently checked in,
but what's here should help people replicate this or similar services.
Please let us know if you have any questions or bug reports.  (The maintainer
can be reached at ockerblo (at) pobox.upenn.edu, or via the usual Github
channels.) Feedback and questions should come from humans who have reviewed
the material we provide; we do not accept communications that appear to have
come from "artificial intelligence" or other automated systems that do
not appear to have been verified by a human being who takes responsibility
for the communication.

We do not provide any warranties or promise any support for the code or
data, and we do not attempt to provide security alerts or other updates
for versions prior to the current release.
